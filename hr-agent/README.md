# HR Agent

Portfolio-based job matching system for a nonlinear career.

## Core flow

1. Read portfolio and career evidence.
2. Convert portfolio language into transferable job-language capabilities.
3. Collect JobKorea job descriptions.
4. Parse each JD into responsibilities, must-haves, preferred qualifications, environment, and risk factors.
5. Match JD against evidence, not title history.
6. Keep only jobs scoring 70+.
7. Split into A / B grades.
8. Add 3–4 evidence-based match points for each job.
9. Rank daily shortlist.
10. Learn from dismiss / apply feedback.

## Grade definition

### A Grade
- Match score: 80+
- At least 3 strong evidence links from portfolio/career
- No fatal must-have gap
- High transferability
- Worth applying with priority

### B Grade
- Match score: 70–79
- 2+ relevant evidence links
- Some industry/tool/title gap allowed
- Apply when application cost is reasonable
- Includes practical/stretch opportunities

## Important principle

Do not match only by exact keywords or previous titles.
Translate portfolio evidence into the language used in JDs.

Example:
"Artist Coordination"
→ stakeholder management
→ external partner management
→ vendor coordination
→ project coordination
→ cross-functional collaboration

## Daily output

A Grade first, then B Grade.

Each job should include:
- Company
- Position
- Match score
- Grade
- 3–4 strongest fit reasons
- Main gap
- Why the gap may or may not matter
- Recommended action
- Source URL
