The Syntax of Your Movement

Starting point

SAKK(Syntax of Aesthetic Kinetic Kinship)를 움직임·형태·감정이 서로 연결되는 방식을 탐구하는 시스템으로 설정했다. 옷의 형태가 완성된 상태로 몸에 놓이는 것이 아니라, 입는 사람의 움직임과 선택에 따라 계속 달라지는 시즌을 기획했다.

Direction

Movement / Memory

형태를 감정의 흔적으로 해석하고, 조각적인 인상과 실제로 입을 수 있는 구조를 함께 고려했다. 몸의 리듬에 따라 실루엣이 변하면서 착용자가 형태를 만드는 과정에 참여하도록 디자인했다.

Kinetic Top은 움직임을 미세한 단위로 나누어 동작을 조형적으로 다루는 옷이다. Memory Skirt는 형태를 기억하는 트윌 메모리 원단을 활용해, 착용자의 선택이 실루엣에 남도록 구성했다.

Execution

Kinetic Top과 Memory Skirt의 제품 개발을 통해 움직임과 기억이라는 방향을 구체화했다. 특히 Memory Skirt는 앞뒤를 고정하지 않고, 입을 때마다 여밈 위치를 선택해 형태를 만들 수 있도록 설계했다. 소재의 특성과 여밈 구조, 몸의 움직임을 하나의 디자인 조건으로 연결하고 룩북으로 정리했다.
